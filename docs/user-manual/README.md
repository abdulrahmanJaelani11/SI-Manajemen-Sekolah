# 📚 Paket Buku Panduan Pengguna (User Manual)
## Sistem Informasi Manajemen Sekolah Terpadu (SIMS) v1.0

Dokumentasi resmi ini disusun berbasis peran pengguna (*Role-Based Segmentation*) untuk memandu seluruh pemangku kepentingan sekolah dalam mengoperasikan sistem secara mandiri, akuntabel, dan profesional. Seluruh berkas manual disajikan dalam format **Microsoft Word (`.docx`)** menggunakan template cover resmi Canva, tata letak standar A4, dan penomoran bab di halaman baru.

### 🎨 Ketentuan Format Standar yang Diterapkan:
1. **Cover Eksklusif (Canva Template):** Menggunakan grafis banner resolusi tinggi, subjudul spesifik per buku, serta area kosong untuk penyematan Logo, Nama Sekolah, dan Versi/Tahun saat resmi diimplementasikan oleh sekolah.
2. **Lembar Kontrol Dokumen:** Tertera pada Halaman 2 lengkap dengan Nomor Dokumen, Target Pengguna, Versi Sistem, dan Status Pengesahan.
3. **Standar Bab (New Page):** Setiap bab utama selalu dimulai pada halaman baru (*New Page*).
4. **Border Tabel Seragam:** Seluruh sisi tabel (Atas, Bawah, Kiri, Kanan, dan Garis Dalam) konsisten menggunakan warna abu-abu lembut institusi (`#CBD5E1`).
